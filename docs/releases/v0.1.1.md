# Super Metroid 3DS Native 0.1.1

This ROM-free update focuses on Old 3DS performance and hardware diagnostics.
The installed CIA now requests the same system-core CPU-time limit as the 3DSX.

## Changes

- Reduced background tile work and unused color-math passes, including in widescreen scenes.
- Added recent frame timings and display-buffer captures to debug dumps for hardware comparisons.
- Fixed the long wait when HOME or POWER closes the application.
- Updated the large CIA banner to a cartridge design. The small HOME icon is unchanged.

See the [full changelog](https://github.com/NicolasBeatum/sm-3ds-native/blob/dev/CHANGELOG.md#011---2026-09-29).

## Install

Download `SuperMetroid3DSPort.3dsx` for the Homebrew Launcher or scan this QR code with FBI's **Remote Install → Scan QR Code** to install `SuperMetroid3DSPort.cia`:

![FBI QR code for the v0.1.1 CIA](https://github.com/NicolasBeatum/sm-3ds-native/releases/download/v0.1.1/fbi-v0.1.1.png)

Place your own compatible `.smc` or `.sfc` ROM in `sdmc:/3ds/sm3dsnative/` and choose it in the ROM selector. No game ROM or translation patch is included in either build.
