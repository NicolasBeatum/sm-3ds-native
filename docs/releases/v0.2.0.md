# Super Metroid 3DS Port 0.2.0

Atmospheric lighting, map QoL and transparent HUD modes for Old and New 3DS.
A development CIA has been played from start to finish on Old 3DS. This confirms
a route to the ending, not every route or 100% completion.

## Highlights / Novedades

- Optional atmospheric lighting throughout the game: colored doors, lava,
  background lamps, Samus, selected enemies and short shadows. Original
  presentation remains available with LIGHTING OFF.
- Five upper HUD modes, including transparent energy/minimap and expanded scenery.
- Map item styles: OFF, ZERO/FUSION or SUPER METROID, with a separate upper-minimap
  toggle. Colored door faces turn blue when their native lock is unlocked;
  room colors distinguish heat, lava, acid and secrets.
- Lower-map stations: **E = energy refill / recarga de vida**,
  **A = ammo refill / recarga de munición**, **M = map station / estación de mapas**.
  Native **S** save markers remain. Samus has a small red position marker.
- English/Spanish lower-screen menus, individual map QoL help pages and persisted
  settings. Language is under SETUP → HUD; map improvements are under SETUP → MAP.
- Shaktool movement correction, original SPC/DSP audio queue improvements,
  suspend/resume handling and background rendering optimizations.
- Bilingual README with updated E/A/M map captures and OFF/ON GIFs from ten areas.

## Download / Instalación

- **SuperMetroid3DSPort.cia**: install with FBI, or scan the QR below using
  **Remote Install → Scan QR Code**.
- **sm-3ds-native-0.2.0-3dsx.zip**: extract the 3DSX and SMDH together for
  Homebrew Launcher. Individual files are also provided.
- Supply your own compatible `.smc` / `.sfc` ROM in `sdmc:/3ds/sm3dsnative/`
  and select it at startup. No game ROM or translation patch is included.
- Existing saves and preferences are preserved. / Se conservan partidas y ajustes.

## Performance / Rendimiento

Performance varies by room, console and settings; 60 FPS is not guaranteed.
The two latest Maridia dump reconstructions use 29–32% fewer drawing pieces at
400px with lighting ON, with identical rendered pixels. Host model/packing time
improves about 4% in the stationary cases. These are reconstruction measurements,
not new console FPS: the original Old 3DS dumps measured approximately 38–39 FPS.
The latest optimization still needs fresh hardware measurements.
