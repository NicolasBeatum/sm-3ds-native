# Next CIA banner concept

`sm-3ds-native-space-256x128.png` is the proposed image for a future CIA banner. The full resolution artwork is `sm-3ds-native-space-full.png`.

The upper 3DS screen uses pixels from `super-metroid-intro-reference.png`, cropped to the game image and projected onto the screen with nearest-neighbor sampling. No generative redraw or color adjustment was applied to that screen.

This concept is saved for a later build. The current `resources/banner.png` and `resources/build-banner.sh` are unchanged.
