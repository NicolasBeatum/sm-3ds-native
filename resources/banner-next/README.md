# CIA space banner

`sm-3ds-native-space-256x128.png` is the approved CIA banner image. The full resolution artwork is `sm-3ds-native-space-full.png`.

The upper 3DS screen uses pixels from `super-metroid-intro-reference.png`, cropped to the game image and projected onto the screen with nearest-neighbor sampling. No generative redraw or color adjustment was applied to that screen.

This composition is now used by `resources/banner.png`. `resources/build-banner.sh` copies the approved 256×128 image verbatim. The small HOME-menu icon is unchanged.
